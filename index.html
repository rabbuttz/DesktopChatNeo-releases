DesktopChat Neo

デスクトップの片隅で、アバターと一緒におしゃべり。

Windows 版をダウンロード
Windows 10 / 11（64bit）

インストールのしかた

  1. ダウンロードした DesktopChatNeo-Setup を開きます。
  2. 「Windows によって PC が保護されました」と出たら、詳細情報 → 実行 を押してください。
  3. 画面の案内に沿ってインストールすると、画面の左下にアバターが出てきます。

つかいかた

  • 左下の端にカーソルを近づけるとメニューが出ます。
  • Ctrl + Alt + 矢印キーで、画面の端へ移動できます。
  • Ctrl + Alt + Shift + 矢印キーで、別のディスプレイへ移動できます。
新しいバージョンは自動で届きます。一度インストールすれば、あとはアプリが勝手に最新になります。
